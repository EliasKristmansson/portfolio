# Portfolio

Personal portfolio built with Next.js, React, Tailwind CSS v4 and Three.js (GLSL shaders).

## Scripts

- `npm run dev` – start the dev server
- `npm run build` – production build
- `npm run lint` – ESLint

## Content

- Projects and expertise: `src/app/data/projects.js`
- Contact details, location and CV link: `src/app/data/profile.js`
- Project images: `public/projects/project-0X/` (see the README there)
